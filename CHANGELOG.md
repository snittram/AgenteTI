# Changelog

Numeração: começa em 1.0 e sobe +1 depois do ponto a cada alteração (1.0 → 1.1 → 1.2 … 1.9 → 1.10 → 1.11).
A versão fica em `modules\Core.psm1` (`$script:AgenteTIBuild`).

## 1.0 (22/11/2026)

- Versões reiniciadas: o AgenteTI passa a ser numerado a partir de 1.0 (antes, Build 3.69).
- Instalador `AgenteTI-Setup-<versão>.exe` com ícone e todos os arquivos compactados; instalação silenciosa com `/S`.
- `AgenteTI.exe`: abre a janela sem a janela preta do Terminal do Windows 11; os atalhos passam a usá-lo.
